## 🔴 Cuarta vez el mismo bug de Windows

```
✗ Admin: Could not resolve entry module
  "../../../../../../C:/Users/svargas/.../pages/Admin.jsx"
```

Mirá la ruta: seis `../` y después **`C:/Users`**. Rollup recibe una ruta
absoluta de Windows y le calcula una relativa encima.

Es `.pathname` otra vez, en `scripts/smoke-render.mjs:31`:

```js
path.dirname(new URL(import.meta.url).pathname)
```

En Windows devuelve `/C:/Users/...` con barra inicial. Ya lo arreglé en tres
tests; este quedó afuera.

**Las 9 páginas montan perfecto.** El reporte era falso: era el script que no
podía encontrar los archivos.

### Por qué R19 no lo detectó

La regla que escribí para esto **sólo revisaba `src/`**. El bug estaba en
`scripts/`.

Corregido: R19 ahora incluye los scripts. Y al hacerlo se detectó a sí misma
—`guard.js` contiene la expresión que busca el patrón—, así que se excluye
explícitamente.

Cuatro veces. **Yo verifico en Linux y vos corrés en Windows**, así que cada

Con R19 cubriendo `src/` y `scripts/`, esta clase de bug ya no puede llegar a

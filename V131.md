## 🔴 Los 3 tests que fallaban en Windows

```
Error: ENOENT: no such file or directory
path: 'C:\C:\Users\svargas\Black-Sheep\...\styles'
```

Mirá la ruta: **`C:\C:\Users`**, la letra de unidad DUPLICADA.

```js
new URL('.', import.meta.url).pathname
```

En Windows eso devuelve `/C:/Users/...` **con barra inicial**, y `path.join`
arma `C:\C:\Users\...`. En Linux devuelve `/home/...` y funciona.

Es la tercera vez en dos días que un bug sólo de Windows llega a tu máquina:
el `tsc.cmd`, las barras invertidas del guard, y ahora esto. **Yo verifico en
Linux y vos corrés en Windows.**

Corregido con `fileURLToPath()`. Y llegamos a la misma solución por separado —
usé la versión del ZIP que mandaste, que es más idiomática:

```js
const DIR = path.dirname(fileURLToPath(import.meta.url))
```

**Guard R19** nuevo: bloquea cualquier `.pathname` sobre `import.meta.url`.

## El patch: accesibilidad

`prefers-reduced-motion` en los componentes animados de la web:
`CursorGlow`, `LiveToasts`, `NetworkGraph`, `PageLoader`, `ScrambleText`.

No es cosmético: para alguien con sensibilidad vestibular, un cursor con estela
y texto que se descompone producen mareo real. El sistema operativo ya expone
esa preferencia; respetarla es lo mínimo.

Más ajustes en `error.tsx`, `layout.tsx`, `api/leads`, `offline.js`, `App.jsx`,
`.gitignore` y `SEGURIDAD.md`.

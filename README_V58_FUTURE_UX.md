# Black Sheep V5.8 — Future UX

## Product thesis
The app should feel like a commercial cockpit: fewer decisions for the seller, more context per action.

## V5.8 changes
- North Star command center on Hoy.
- Next-best-action surfaced from existing recommendation engine.
- Three high-signal shortcuts: risk, focus, captured orders.
- Manager view gets an Executive Pulse layer focused on decisions rather than raw KPI reading.
- Visual system upgraded with depth, glass/ambient layers, responsive desktop behavior and restrained motion.
- No new backend tables or external AI dependency. Existing data and recommendation logic remain the source of truth.

## Design principles researched
Current sales products increasingly converge on:
1. one focused workspace;
2. suggested next-best actions;
3. account context immediately before action;
4. AI/automation that reduces admin rather than adding another dashboard;
5. mobile-first, one-tap workflows.

Sources: HubSpot Sales Workspace / Guided Selling / Mobile and Salesforce Mobile Seller-Focused Experience / Agentforce.

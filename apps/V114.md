## Mi opinión del paquete

**Es bueno, y el diseño es el correcto.** Base `V11.3.7` — descendiente
directo de mi V11.3, así que integrarlo costó minutos en vez de una tarde.

### Lo que está bien pensado

**La lógica NUNCA escribe en Supabase.** Devuelve un `applyPlan` que la UI
aplica sólo tras confirmación explícita, y genera una auditoría del import.

Para una carga masiva de precios eso no es un detalle: un CSV mal armado que
escribe directo puede arruinar la lista de precios de 400 SKU sin vuelta atrás.
El patrón *previsualizar → diferencia → validar → confirmar → auditar* es
exactamente el que corresponde.

**`parseNumber` maneja el formato chileno.** `1.234,56` → `1234.56`. Es el
error clásico al importar un Excel en español, y está resuelto.

**`detectDelimiter` distingue `;` de `,` ignorando lo que va entre comillas.**
Excel en español exporta con punto y coma; sin esto, cada archivo entraría
como una sola columna.

## 🔴 Dos problemas que encontré

### 1 · `catalogControlCenter.test.js` no corría

```js
import { describe, it, expect } from "vitest";
```

**`vitest` no es dependencia de este proyecto.** `npm test` salteaba el
archivo: se veía como cobertura y **nunca se ejecutó**.

Es el mismo patrón de confianza falsa que ya detectamos con el parser de CSS
que "pasaba leyendo nada". Un test que no puede fallar es peor que no tenerlo.

Lo reescribí a `node:test`. **Corre y pasa: 5 tests.**

**Guard R18 nuevo:** bloquea cualquier `.test.js` que importe `vitest`, `jest`
o `mocha` sin estar instalados.

### 2 · `catalogControlCenter.js` no está cableado

`Admin.jsx` importa `exportCsv` e `importCatalogo`, pero **no el Control
Center**. Los 175 líneas de diff/validación/plan están en el repo sin que
ninguna pantalla las use.

Es exactamente lo que pasó con `GoalCard`: escrito, con tests, y dos meses
esperando a que alguien lo conectara — con un import roto adentro que nadie
vio porque nunca se ejecutaba.

**Lo dejé integrado pero lo marco:** si en la próxima no se cablea, mejor
sacarlo que dejarlo como andamiaje.

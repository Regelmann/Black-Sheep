# V13.2 — Cierre de confianza, RLS y offline

**Fecha:** 2026-09-01
**BUILD_STAMP:** `v-BS-PLATFORM-V13.2`

## Qué cambió

### Seguridad / multi-tenant
- `sql/47_RLS_CIERRE_FINAL.sql` — cierra **todas** las políticas
  `USING(true)` residuales de los SQL históricos y cubre tablas que
  `28`/`35` no cubrían (`gerencia_clientes`, `encuestas_visita`,
  `decision_feedback`).
- `sql/48_AUDITORIA_TIMESTAMPS.sql` — `updated_at` + trigger
  `touch_updated_at()` en tablas editables.

### Offline-first
- `lib/snapshotDb.js` — snapshot de cartera migrado a IndexedDB (doble
  escritura: espejo en memoria + IndexedDB + localStorage como respaldo).
- La cola offline ya estaba en IndexedDB; ahora el snapshot también.
- Migración transparente desde `kf_offline_v1`.

### Idempotencia total del outbox
- `handleNota`, `handlePedido` y `handleNoVenta` ahora mandan
  `client_op_id` y tratan `23505` como éxito.
- Ante error de esquema degradan sin la columna; ante RLS/red reintentan
  completo (no se mutila la fila).

### Pedido
- `lineasValidas()` y `totalLineas()` como fuente única.
- `guardarPedido`, `totalPedido`, WhatsApp cliente, WhatsApp bodega y PDF
  formal usan las mismas líneas: se elimina el caso donde se cobraba una
  línea fantasma.

### Data Health
- `domain/DataHealthCard.jsx` — semáforo verde/ámbar/rojo.
- Agregado en `Gerencia` y `DashboardGerencia`, antes de los números.

### Web
- Lint sin errores (PageLoader, ScrambleText, CursorGlow, NetworkGraph,
  error.tsx, LiveToasts).
- CI nuevo: job `verify-web` (lint + typecheck + build + artifact `.next`).

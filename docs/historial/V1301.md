# v-BS-PLATFORM-V13.0.1 — Verify que funciona en Windows

**549/549 tests · 62 avisos (eran 156, 94 eran falsos) · build ✓**

## 🔴 1 · El typecheck no corría en Windows

```
❌ tsc falló sin emitir diagnósticos. Salida cruda: (vacía)
```

En Windows el binario es **`tsc.cmd`**, un script de shell. `execFileSync`
**no puede ejecutarlo directo**: falla sin salida, y el script —bien
programado— se negaba a interpretar eso como éxito.

En Linux nunca se notó porque ahí el binario es un ejecutable normal. **Yo
verifico en Linux y vos corrés en Windows**, así que este bloqueo era invisible
para mí.

Ahora usa `node node_modules/typescript/bin/tsc`, que funciona igual en los
tres sistemas.

## 🔴 2 · Los 156 avisos de ESLint eran falsos

```
'Routes' is defined but never used
'Hoy' is defined but never used
'PageShell' is defined but never used
```

**ESLint no sabía que `<Routes>` usa la variable `Routes`.** Sin el plugin de
React, ve un import sin referencias en JavaScript plano y lo marca como no
usado. Marcaba prácticamente **todo**: cada página, cada componente, cada icono.

Con `react/jsx-uses-vars`: **156 → 62**. Los 94 que desaparecieron eran mentira.

Y esto importa más de lo que parece: **156 avisos falsos entierran los
reales**. Es peor que no tener lint — te enseña a ignorar la salida. Los 62 que
quedan sí son de verdad: imports que sobran y 12 dependencias de hooks
incompletas.

## Sobre el ZIP anterior

El deploy falló tres veces y ninguna fue culpa del código:

| | |
|---|---|
| `~/Downloads` no existe | tu carpeta es `Descargas` |
| `/tmp` se vacía entre comandos | Git Bash sobre Windows |
| comandos sin `&&` | `rsync` falló y el `git push` corrió igual |

`~/bs-tmp` funciona. Este es el bloque bueno, todo encadenado:

```bash
mkdir -p ~/bs-tmp && rm -rf ~/bs-tmp/* && \
cp "$(find /c/Users/svargas -name 'BLACKSHEEP_V1301.zip' 2>/dev/null | head -1)" ~/bs.zip && \
unzip -q ~/bs.zip -d ~/bs-tmp && \
[ -d ~/bs-tmp/apps/field/src ] && \
cd ~/Black-Sheep/Black-Sheep && \
rsync -av --delete --exclude='.git' --exclude='node_modules' \
  --exclude='dist' --exclude='.env' --exclude='.next' ~/bs-tmp/ . && \
cd apps/field && npm ci && npm run verify
```

El commit y el push van **aparte**, después de mirar `git status`.

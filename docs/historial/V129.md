## ✅ Arreglados

### 🔴 Los pines del mapa · el mejor hallazgo

```js
if (item._tipo === 'prospecto') return 'var(--ok-mid)'
```

Esos colores se inyectan en un **`data:image/svg+xml`**, que el navegador
trata como un **archivo aparte**: no tiene acceso al CSS de la página.
`var()` no resuelve ahí dentro, el `fill` queda inválido → **negro**.

Por eso viste 2.834 pines negros iguales: no se distinguía un prospecto de un
cliente activo ni de uno en riesgo.

Los colores del SVG ahora van en **hex**. Y los filtros usan los mismos, así
que la pastilla sirve de leyenda:

```
ruta #1d4ed8 · prospecto #16a34a · activo #2563eb
riesgo #f59e0b · perdido #ef4444 · bloqueado #93c5fd
```

header, 9px, casi transparente.

### El selector de ejecutivos

### El buscador con otra tipografía
Los `<input>` **no heredan `font-family`**: el navegador les pone la suya. Un
`font-family: inherit` global lo resuelve en toda la app.

### Los filtros incompletos

ven todas.

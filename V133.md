# v-BS-PLATFORM-V13.3 — Limpieza medida

**549/549 tests · smoke ✅ · build ✓**

Limpieza **midiendo**, no borrando a ojo. Es la lección de V12.7, donde borré
242 bloques de CSS por un criterio equivocado y rompí la UI.

## 🔴 Lo mejor: el smoke test encontró un import roto

`scripts/smoke-render.mjs` estaba en el repo, **funcionaba, y no se ejecutaba
nunca** — no estaba en `package.json` ni en el CI.

Al correrlo:

```
❌ 6 página(s) no montan. Eso es una pantalla en blanco.

import { enqueueAction, isProbablyOffline, nuevoOpId } from './offline.js'
                                           ^
```

**`nuevoOpId` existía pero no estaba exportada.** `lib/nota.js` la importaba —
y `nota.js` es el archivo que cablée en seis pantallas la versión pasada para
que las notas no se pierdan sin señal.

**Habría sido pantalla blanca en producción.** Los 549 tests no lo detectaron:
verifican módulos sueltos, no que las páginas monten.

Ahora `smoke` es parte de `verify`. Son **seis capas**:

```
lint → typecheck → guard → test → smoke → build
```

Esta es exactamente la verificación que faltó cuando rompí el CSS.

## La medición

Mi primer script dijo **26 huérfanos**. Estaba mal: no detectaba
`lazy(() => import(...))`, así que marcaba todas las páginas. Corregido: **7**.

De esos 7, no todos son basura:

| | Decisión |
|---|---|
| `chrome/index.js` · `domain/` · `shells/` · `ui/` | **Borrados.** Barriles que nadie importa: siempre se usa el archivo directo |
| `hooks/useVendorGps.js` | **Borrado.** `lib/geo.js` ya lee el GPS, y `Ruta.jsx` lo reimplementó a mano. Era el tercer duplicado |
| `hooks/useGoalCalculation.js` | **Borrado.** Re-export de `calcGoal`; hasta su propio test importa de `lib` |
| `lib/push.js` | **NO se borró.** 149 líneas correctas, 7 tests, SQL desplegable. Le falta un botón |

`push.js` queda marcado en `lib/PENDIENTE_PUSH.md`: si en dos versiones sigue
sin cablearse, conviene sacarlo. Es el patrón de `GoalCard`, que estuvo dos
meses en el repo con un import roto adentro porque nadie lo usaba.

# KEYFOODS Field V56.15 — COMMERCE SUPERIOR

Versión superior a V56.13 UX Premium y V56.14 Catálogo Full.

## Qué resuelve (regla de negocio)

1. **Base de precios = Excel de lista**  
   Script `KEYFOODS_PATCH_STOCK_PRECIOS.py` escribe `precio_unidad` / `precio_caja` / `precio_kilo` en `stock`.

2. **Solo se ofrece con stock**  
   El catálogo marca `stock_disponible` y el pedido público valida SKUs contra stock u oferta.

3. **Jerarquía de precio al cliente**  
   - Histórico del cliente (si existe) → “Tu precio”  
   - Si no → lista Excel  
   - Ejecutivo puede negociar → “Negociado”  
   - Nunca muestra $0 (Consultar)

4. **Orden comercial del catálogo**  
   1. Para repetir hoy (smart reorder)  
   2. **Mis productos · reposición**  
   3. **Ofertas y focos del mes**  
   4. **Corta fecha / liquidación**  
   5. Catálogo completo (lista Excel)

5. **Stock field**  
   Vista “Stock diario · operativa” con filtros Foco / Corta fecha / Sobrestock y precio de lista visible.

```sql
-- precios cargados
select count(*) filter (where coalesce(precio_unidad,0)>0) from public.stock;

-- catálogo (reemplazar TOKEN)
select jsonb_array_length(get_public_catalogo('TOKEN')->'items');
```
